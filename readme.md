# 🌳 App Gestão Agrícola - Porto Seguro, BA

Sistema inteligente para controle de adubação, espaçamento e manejo de consórcios agrícolas, personalizado para as culturas do Extremo Sul da Bahia.

## 🚀 Funcionalidades
* **Inteligência de Nutrição:** Sugestões de NPK (04-14-08, 10-10-10, 12-06-12, etc.) conforme a idade da planta.
* **Cronograma Alternado:** Separação entre adubos minerais e orgânicos (Esterco, Farinha de Osso e Cinzas) para saúde do solo.
* **Guia de Espaçamento:** Medidas exatas para consórcios (ex: Banana da Terra + Cacau).
* **Banco de Dados Completo:** +20 culturas incluindo Abacate, Coco, Café, Pimenta-do-reino e mais.
* **Privacidade e Backup:** Dados salvos no navegador com opção de backup via WhatsApp.

## 🛠️ Tecnologias
* HTML5 / CSS3 (Dark Mode)
* JavaScript (Local Storage)
* Markdown (Documentação)

## 📖 Como Usar
1. Suba o arquivo `index.html` para o GitHub Pages.
2. Cadastre suas plantas e as datas de plantio.
3. O sistema calculará automaticamente as próximas datas de adubação.
